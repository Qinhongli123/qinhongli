Agent（智能体）

一句话理解：以大模型为"大脑"，能自主理解目标、拆解任务、调用工具并根据反馈调整行动，直到把事情做完的 AI 系统。

🏠 概念关系图 · Agent · 大模型的上下文 · Skill

1概念定义

大白话版：普通 AI 聊天机器人像"客服"——你问一句它答一句；而 Agent 像"助理"——你只说要达成什么结果，它自己去想步骤、找工具、干活、检查，最后把成品交给你。
规范定义：Agent（智能体）是一种以大语言模型（LLM）为核心决策单元，能够感知任务环境、自主规划行动步骤、调用外部工具执行操作，并依据执行反馈迭代调整，直至达成给定目标的智能系统。

2核心机制

🧠 规划（Planning）

把"帮我做一份竞品周报"这样的大目标，拆解成"查数据 → 清洗整理 → 找出变化 → 写结论"这样的子任务序列，并决定先做哪个。

🔧 工具调用（Tool Use）

知道自己"不会"的事情就去找工具：联网搜索、读文件、运行代码、调 API。工具调用让 Agent 突破了纯文本的能力边界。

📚 记忆（Memory）

短期记忆靠上下文窗口（本次任务内的信息），长期记忆靠外部存储（向量数据库、文件），让它能"记得"之前发生过什么。

🔁 反馈循环（Reflection）

每做完一步就检查结果：代码报错了就改，搜到的资料不对就换关键词。不是"一次生成定终身"，而是迭代逼近目标。

目标输入 → [ 规划拆解 ] → [ 调用工具执行 ] → [ 检查反馈 ]
　 ↑＿＿＿不满足则回到规划，调整后再执行＿＿＿↓
　 → 输出最终成果

3应用案例（广告学视角）

案例：竞品投放监测周报 Agent
我给 Agent 一个目标："每周一早上 9 点前，给我一份上一周三个竞品在抖音/小红书的投放内容监测简报。"
Agent 自主执行：① 用搜索工具抓取三个品牌账号上周发布的内容；② 提取每条内容的主题、形式（图文/短视频/直播）、互动数据；③ 对比本周与上周的变化，找出投放策略调整的信号；④ 把结论写成简报并在周一早上推送给我。
整个过程我只需要下达一次目标、最后验收成品——这正是 Agent 与普通 AI 工具的本质区别：从"我来操作工具"变成"我验收 Agent 的工作"。
案例：A/B 测试文案 Agent
输入产品卖点与目标人群，Agent 自动产出 5 组不同切入角度的信息流广告文案初稿 → 调用投放平台的测试接口小流量试投 → 根据点击率数据淘汰低效版本 → 用表现最好的文案结构裂变出第二批。人只负责把控品牌调性与合规红线。

4概念辨析：Agent ≠ 聊天机器人

对比维度聊天机器人（Chatbot）Agent（智能体）
交互模式被动应答：一问一答，答完即止主动执行：接收目标后自主推进多步任务
任务长度单轮或几轮对话可长时间、多步骤运行直至完成
工具使用一般只能生成文本能联网搜索、执行代码、读写文件、调用外部 API
纠错能力答错了等用户发现自我检查反馈，发现错误自动调整重试
广告场景类比客服机器人回答"运费多少"助理替你跑完"调研—产出—复盘"全流程

5自测问题（点击展开参考答案）

Q1：判断一个 AI 产品是不是 Agent，最关键的判断标准是什么？
看它是否具备自主性：能否在只给定目标（而非逐步指令）的情况下，自己完成"规划—执行—反馈—调整"的闭环。如果每一步都需要人来推动，那它只是对话工具；能自己跑完流程的才是 Agent。
Q2：为什么说"工具调用"是 Agent 的关键能力？没有它 Agent 会怎样？
没有工具调用，Agent 只能基于训练数据"说"，不能对现实世界"做"——不能查实时数据、不能执行代码、不能操作文件。工具调用把大模型从"知识问答机"升级为"能干活的执行者"，这是 Agent 完成真实任务的物理基础。
Q3：结合广告学专业，举一个"只能用 Agent 而不能用普通 AI 对话"的场景。
例：每月自动汇总 5 个竞品的全平台投放数据并输出趋势报告。这需要跨周期、多步骤、调用外部数据接口并主动定时执行——普通对话式 AI 每次都要人工重新输入指令、手动喂数据，无法自主完成闭环任务。
Q4：Agent 的"记忆"分哪两种？分别对应什么机制？
短期记忆 = 上下文窗口（详见本系列第二篇），保存当前任务内的对话与中间结果，任务结束即失；长期记忆 = 外部存储（数据库/文件），跨任务持久保存，需要时检索回来放进上下文使用。
